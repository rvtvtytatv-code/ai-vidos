# Royal AI Studio — финальный фикс

## Что изменено

- Заголовок кейсов переделан в крупный манифест: «Работы, которые останавливают скролл».
- Блок услуг оформлен тремя крупными карточками в стилистике сайта.
- Этапы работы переделаны в формат «Понятный маршрут. Не магия.» с четырьмя последовательными карточками.
- Блок о студии переделан в режиссёрский манифест: «Нейросеть — это камера. Режиссура остаётся за нами.»
- Исправлены переносы: слова не разрываются посередине, текст не обрезается.
- Видео кейсов запускаются только после нажатия кнопки «Пуск».
- Убраны пины над кейсами.
- Сохранены страницы политики персональных данных и согласия на обработку данных.

## Запуск

На Windows запустите:

```text
start-site.bat
```

Либо в PowerShell:

```powershell
npm start
```

Откройте:

```text
http://localhost:3000
```

## Файлы GIF

Положите в папку `assets`:

```text
hero-01.gif
hero-02.gif
hero-03.gif
```

## Видео кейсов

Положите рядом с `index.html`:

```text
case-01.mp4
case-02.mp4
case-03.mp4
```

После замены файлов перезапустите сайт и обновите страницу через `Ctrl + F5`.
